# Быстрый скрин

Маленькая программа для Windows 10/11: выделяете область экрана — снимок **сразу** сохраняется в выбранную папку. Без редактора и без лишних окон.

* Один файл `BystryjSkrin.exe` (~170 КБ), без установки и без прав администратора. Нужен .NET Framework 4.8 (уже есть в Windows 10 1903+ и Windows 11).
* Живёт в трее (возле часов). Скриншот: **Ctrl+Shift+S**, щелчок по значку или пункт меню «Сделать скриншот».
* Экран «замораживается» и затемняется, выделяете рамку мышью — видно размер в пикселях. **Esc** или **правая кнопка** — отмена.
* Правильно работает на нескольких мониторах с разным масштабом (Per-Monitor DPI v2) и с мониторами слева/сверху от основного.
* Файлы: `Скриншот 2026-10-03 14-25-07.png` (или JPG), существующие файлы никогда не перезаписываются — добавляется ` (2)`.
* По умолчанию папка `Изображения\Скриншоты`, меняется через «Выбрать папку…» или «Настройки».

## Меню значка в трее

| Пункт | Что делает |
|---|---|
| **Сделать скриншот** | то же, что Ctrl+Shift+S или щелчок по значку |
| Отменить последний скриншот | перемещает последний снимок в Корзину (Ctrl+Shift+Z) |
| Открыть папку | открывает папку со снимками |
| Выбрать папку… | выбор папки (системные и недоступные папки не принимаются) |
| Настройки… | формат PNG/JPG, качество, сочетания клавиш, буфер обмена, уведомление, звук, перекрестие, автозапуск |
| Автозапуск с Windows | через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, без администратора |
| Выход | |

После сохранения в углу экрана на несколько секунд появляется уведомление «Сохранено: …» с кнопками **Открыть**, **Папка**, **Удалить** (удаление — в Корзину). Наведите мышь — уведомление не исчезнет.

Настройки хранятся в `%APPDATA%\BystryjSkrin\settings.ini`, журнал ошибок — там же, `log.txt`.

## Защита от ошибок

* **Случайный щелчок** или рамка меньше 5×5 пикселей — ничего не сохраняется, выделение остаётся открытым, можно выделить заново.
* **Повторное нажатие** сочетания, пока выделение открыто, игнорируется.
* **Esc** срабатывает, даже если фокус случайно ушёл в другое окно; правая кнопка мыши отменяет всегда.
* **Передумали** — Ctrl+Shift+Z или «Удалить» в уведомлении: снимок уходит в Корзину, его можно восстановить.
* **Папка пропала** (флешку вынули, сетевой диск отключён, нет прав, кончилось место) — снимок всё равно сохраняется в запасную папку: `Изображения\Скриншоты` → `C:\Users\<имя>\Скриншоты` → `%LOCALAPPDATA%\BystryjSkrin\Скриншоты` → временная папка. Появляется понятное сообщение с причиной и путём к файлу. Если не получилось нигде — снимок копируется в буфер обмена.
* **Сочетание занято** другой программой — программа сразу говорит об этом и предлагает свободное (например, Ctrl+Alt+S).
* **Опасные сочетания** не принимаются: Win+Shift+S («Ножницы»), Ctrl+C/V/S/Z…, Alt+F4, одиночные буквы, Shift+буква.
* **Системные папки** (Windows, Program Files, ProgramData, корень диска, Корзина) и неверные пути не принимаются. Испорченный файл настроек сбрасывается с предупреждением.
* Любая непредвиденная ошибка — сообщение по-русски и запись в журнал; программа продолжает работать.

## Если появилась ошибка оператора

Сообщение **«Оператор или администратор отклонил запрос» (0x800710E0, ERROR_OPERATOR)** в Windows 11 чаще всего выдаёт **Планировщик заданий**: программа, запускаемая через задачу, «уже работает», а в задаче стоит «Не запускать новый экземпляр»; или компьютер спал в момент запуска; или задача требует «Выполнять с наивысшими правами», работы только от сети, сохранённого пароля и т.п.

«Быстрый скрин» устроен так, чтобы эти причины не возникали:

* **Нет задач Планировщика.** Автозапуск — только обычная строка в `HKCU\...\Run`. Если вы раньше сами создавали задачу для этой программы — удалите её в Планировщике заданий.
* **Не нужны права администратора** (манифест `asInvoker`), нет UAC-запросов. Не запускайте программу «от имени администратора».
* **Повторный запуск не «отклоняется»**: второй экземпляр просто сообщает, что программа уже в трее (а с параметром `--capture` — сразу делает скриншот в уже запущенной).
* Если Windows выключила автозапуск в «Диспетчер задач → Автозагрузка», программа об этом предупредит; повторное включение «Автозапуск с Windows» в меню снимает этот запрет.

Другие похожие блокировки Windows и что делать:

1. **«Контролируемый доступ к папкам»** (защита от программ-шантажистов в «Безопасности Windows») запрещает незнакомым программам писать в «Изображения», «Документы», «Рабочий стол» — в том числе если эти папки перенесены в OneDrive. Признаки: всплывающее «Несанкционированные изменения заблокированы» и наше сообщение «Сохранено в запасную папку… мешает защита от программ-шантажистов». Решение: «Безопасность Windows → Защита от вирусов и угроз → Управление защитой от программ-шантажистов → Разрешить работу приложения через контролируемый доступ к папкам → Добавить разрешённое приложение» → выберите `BystryjSkrin.exe` (кнопка «Как разрешить» в уведомлении открывает этот раздел). Или выберите папку вне защищённых, например `C:\Users\<имя>\Скриншоты` или `D:\Скриншоты`.
2. **SmartScreen** («Система Windows защитила ваш компьютер») — exe не подписан цифровой подписью. Нажмите **«Подробнее» → «Выполнить в любом случае»**. Можно заранее: правый щелчок по файлу → «Свойства» → отметить «Разблокировать» → OK.
3. **«Интеллектуальное управление приложениями» (Smart App Control)** в Windows 11 блокирует *любые* неподписанные программы, и исключений для отдельных программ у него нет. Проверить: «Безопасность Windows → Управление приложениями/браузером → Параметры интеллектуального управления приложениями». Если там «Вкл.», запустить неподписанный exe можно только выключив эту функцию (в старых сборках Windows 11 обратно её включить можно было лишь переустановкой Windows; в новых — переключателем). Надёжное решение без отключения — подписать exe сертификатом (например, Azure Trusted Signing).
4. **Защищённый экран** (экран блокировки, Ctrl+Alt+Del, окно UAC «Разрешить этому приложению…») снимать нельзя никакой обычной программе: в это время сочетание не сработает, а при попытке появится понятное сообщение. Повторите после того, как окно закроется.
5. **Корпоративные политики** (AppLocker / WDAC) — exe может запрещать администратор. Тогда сообщение будет «Эта программа заблокирована групповой политикой» — нужно разрешение администратора.

Снимок делается обычным способом GDI (BitBlt), а не через Windows.Graphics.Capture, поэтому разрешение «Захват экрана» в параметрах конфиденциальности и рамка захвата не требуются.

## Ограничения

* Защищённое от копирования видео (Netflix, некоторые плееры) на снимке может быть чёрным — так работает DRM.
* На HDR-мониторах снимок через GDI может выглядеть бледнее.
* Ctrl+Shift+S глобально перехватывается: в программах, где это «Сохранить как», оно перестанет работать, пока запущен «Быстрый скрин». Сочетание меняется в настройках; Ctrl+Shift+Z — аналогично (во многих программах это «Повторить»), его можно отключить.
* Отмена (Ctrl+Shift+Z) помнит снимки только текущего запуска программы.

## Для разработчика

```
BystryjSkrin.exe                      запуск в трее
BystryjSkrin.exe --capture            сразу открыть выделение (или попросить об этом уже запущенную копию)
BystryjSkrin.exe --settings           открыть настройки (в запущенной копии)
BystryjSkrin.exe --quit               закрыть запущенную копию
BystryjSkrin.exe --capture-rect x,y,ш,в [--out папка] [--format png|jpg]
                                      снимок области без окна (координаты экрана в пикселях, могут быть отрицательными);
                                      коды выхода: 0 — сохранено, 5 — сохранено в запасную папку, 2 — неверные аргументы, 3 — не снят, 4 — не сохранён
--config-dir папка                    другая папка настроек (для тестов)
```

Сборка: `dotnet build -c Release` (.NET SDK 8+, проект net48 собирается и на Linux благодаря Microsoft.NETFramework.ReferenceAssemblies). Тесты и дымовой тест с настоящим выделением мышью запускаются в GitHub Actions на `windows-latest`; при теге `v*` exe прикрепляется к релизу.
